# 四轴无人机飞行能耗预测实验 1.0：算法、训练与结果说明

本文档说明实验 1.0 的数据来源、输入输出、特征工程、模型结构、训练算法、评价指标和图表读取方法。所有模型参数和算法流程均来自当前代码，样本量、超参数选择结果和测试指标均来自本目录中的实际输出文件。文档对应的统一入口为 [main.py](../main.py)，核心实现位于 [data_utils.py](../data_utils.py)、[model.py](../model.py)、[train.py](../train.py)、[predict.py](../predict.py)、[evaluate.py](../evaluate.py) 和 [visualize.py](../visualize.py)。

## 1. 任务定义

实验对象为 DJI Matrice 100 四轴无人机。程序根据飞行时刻的风速、速度、载荷、高度、加速度、角速度和航线等工况，预测该采样点的电功率；再按采样间隔积分，得到每次飞行的累计电能。

模型直接学习的是“工况特征到瞬时功率”的非线性映射。MLP 是 Multilayer Perceptron 的缩写，中文为多层感知机，本质上是由多层全连接变换组成的前馈神经网络。该模型不是循环神经网络，也没有把连续多个采样点组成时间窗口。时间和飞行进度属于输入特征，但每一行样本仍独立送入 MLP。该设计计算量较低，能拟合稳定巡航功率；对尖峰、突降和具有迟滞效应的动态过程只能依赖当前行特征近似。

完整流程如下。

~~~mermaid
flowchart LR
    A[原始 flights.csv] --> B[数值清洗与航线筛选]
    B --> C[功率标签与物理启发特征]
    C --> D[按 flight 分组划分]
    D --> E[仅用训练集统计量标准化]
    E --> F[5 个 MLP 候选模型调参]
    F --> G[残差 MLP 最终训练]
    G --> H[逐采样点功率预测]
    H --> I[按时间间隔积分为飞行能耗]
    I --> J[指标、CSV 与图表]
~~~

## 2. 数据集介绍

### 2.1 来源与采集设备

数据集名称为 **Data Collected with Package Delivery Quadcopter Drone**，公开镜像地址为 [https://www.modelscope.cn/datasets/OmniData/Data_Collected_with_Package_etc.git](https://www.modelscope.cn/datasets/OmniData/Data_Collected_with_Package_etc.git)。数据由 Carnegie Mellon University 等机构采集，原始说明记录了 209 次飞行任务，采集日期范围为 2019-07-04 至 2019-10-24。

主要设备包括：


| 对象             | 型号或来源               | 数据内容                                     |
| ---------------- | ------------------------ | -------------------------------------------- |
| 无人机           | DJI Matrice 100          | 飞行平台                                     |
| 风传感器         | FT Technologies FT205    | 风速、风向，标称精度 ±0.1 m/s，刷新率 10 Hz |
| GNSS/INS         | 3DM-GX5-45               | 速度、角速度、线加速度等状态量               |
| 电流与电压传感器 | Mauch Electronics PL-200 | 电池电压和电流                               |
| 同步与记录       | ROS、Raspberry Pi Zero W | 将不同传感器数据近似同步到 5 Hz              |

原始 flights.csv 有 257896 行、28 个字段。代码从中读取 19 个字段：flight、time、wind_speed、wind_angle、battery_voltage、battery_current、三轴速度、三轴角速度、三轴线加速度、任务速度、载荷、高度和航线。

### 2.2 清洗后的数据规模

程序把数值转换失败的记录设为缺失并删除，只保留航线名称以 R 或 H 开头的真实飞行、巡航和悬停记录，排除 A 类地面辅助实验。清洗后保留 249210 行、**198 次飞行**。观测功率范围为 0～1004.218 W，平均功率为 403.672 W。有效采样间隔范围为 0.06～2.10 s，平均值约为 0.150 s，因此不能把全部记录理解成严格等间隔序列。

数据按 flight 整组随机划分，随机种子为 42。一次飞行只会进入训练集、验证集或测试集中的一个集合，从数据边界上避免同一飞行轨迹泄漏到多个集合。


| 集合   | 飞行数量 | 记录数量 | 按飞行数量占比 |
| ------ | -------: | -------: | -------------: |
| 训练集 |      138 |   174653 |         69.70% |
| 验证集 |       30 |    34796 |         15.15% |
| 测试集 |       30 |    39761 |         15.15% |
| 合计   |      198 |   249210 |           100% |

航线分布存在明显不平衡：


| 航线 | 飞行数量 | 记录数量 |
| ---- | -------: | -------: |
| H    |        4 |     3794 |
| R1   |      182 |   227551 |
| R2   |        1 |     1445 |
| R3   |        1 |     1364 |
| R4   |        1 |     1197 |
| R5   |        4 |     5490 |
| R6   |        5 |     8369 |

R1 占 182/198 次飞行。测试指标主要反映 R1 及其相似工况，不能据此断言模型在 R2～R6 或新航线上的误差同样稳定。

## 3. 程序输入与输出

### 3.1 数据准备输入

数据准备阶段读取原始 `flights.csv`。每一行表示某次飞行在一个采样时刻的状态，必须包含以下 19 个字段：


| 原始字段                | 中文含义                                                     | 单位或取值                 | 在程序中的用途                                                                            |
| ----------------------- | ------------------------------------------------------------ | -------------------------- | ----------------------------------------------------------------------------------------- |
| `flight`                | 飞行任务编号。同一编号下的多行记录属于同一次完整飞行         | 正整数，无量纲             | 用于按飞行分组划分数据、计算相邻采样间隔和汇总单次飞行能耗，不直接输入模型                |
| `route`                 | 数据集给出的航线类别                                         | 字符串，清洗后为 H、R1～R6 | 转换为 7 个独热编码特征；H 表示悬停类工况，R1～R6 是数据集中的路线类别代码                |
| `time`                  | 当前记录在本次飞行中的时间位置                               | s                          | 直接作为输入，并用于计算`dt_seconds` 和 `flight_progress`                                 |
| `wind_speed`            | 风传感器测得的风速大小                                       | m/s                        | 直接输入模型，并参与风矢量、相对空气速度和通信代理量计算                                  |
| `wind_angle`            | 水平风向角                                                   | deg                        | 不直接输入模型；转换为`wind_sin`、`wind_cos` 及水平风分量                                 |
| `battery_voltage`       | 当前采样点的电池端电压                                       | V                          | 只用于构造真实功率标签，不作为模型输入，避免模型直接由电气量复算功率                      |
| `battery_current`       | 当前采样点的电池电流                                         | A                          | 只用于构造真实功率标签；代码将正电流视为放电电流                                          |
| `velocity_x`            | 无人机沿数据集 x 轴方向的速度分量                            | m/s                        | 用于计算水平速度、三维实际速度、相对空气速度和风向关系                                    |
| `velocity_y`            | 无人机沿数据集 y 轴方向的速度分量                            | m/s                        | 用途与`velocity_x` 相同，x、y 共同描述水平运动                                            |
| `velocity_z`            | 无人机沿数据集 z 轴方向的有符号速度分量                      | m/s                        | 转换为`vertical_speed_mps` 和绝对竖直速度，并参与多个动态特征；正负方向遵循源数据坐标约定 |
| `angular_x`             | 绕 x 轴的角速度                                              | rad/s                      | 与另外两个轴合成为角速度模长，描述姿态变化强度                                            |
| `angular_y`             | 绕 y 轴的角速度                                              | rad/s                      | 与另外两个轴合成为角速度模长                                                              |
| `angular_z`             | 绕 z 轴的角速度                                              | rad/s                      | 与另外两个轴合成为角速度模长                                                              |
| `linear_acceleration_x` | x 轴线加速度                                                 | m/s²                      | 参与重力补偿后的动态加速度模长计算                                                        |
| `linear_acceleration_y` | y 轴线加速度                                                 | m/s²                      | 参与重力补偿后的动态加速度模长计算                                                        |
| `linear_acceleration_z` | z 轴线加速度；当前代码按 NED 坐标约定使用，静止时接近$-g$    | m/s²                      | 加上重力加速度后参与动态加速度模长计算                                                    |
| `speed`                 | 飞行任务中设定的程序速度，不等同于传感器计算出的实际三维速度 | m/s                        | 重命名为`programmed_speed_mps` 后输入模型                                                 |
| `payload`               | 无人机携带的有效载荷质量                                     | g                          | 除以 1000 转换为`payload_kg` 后输入模型                                                   |
| `altitude`              | 飞行任务设置或记录的高度                                     | m                          | 重命名为`altitude_m` 后输入模型，并参与视觉和通信代理量计算                               |

电压和电流不会进入模型的 28 维输入，只用于计算真实功率标签。当前代码把正电流视为放电电流；若新数据采用“放电电流为负”的符号约定，必须先转换符号，否则负电流会被截为 0。

### 3.2 模型输入

模型输入为 28 维特征。其中前 21 维是连续量、角度变换量或依据连续量构造的代理特征，后 7 维是航线独热编码。表中“模型作用”说明该变量向网络提供的信息，不表示模型一定学到了严格的物理因果关系。


| 序号 | 模型字段                       | 具体含义与计算方式                                                                        | 单位或范围                    | 模型作用                                                                     |
| ---: | ------------------------------ | ----------------------------------------------------------------------------------------- | ----------------------------- | ---------------------------------------------------------------------------- |
|    1 | `time`                         | 当前采样点在一次飞行内的时间戳，即从该次记录时间轴起点到当前点的时间位置                  | s                             | 帮助模型区分起飞前、巡航和降落后等通常出现在不同时段的状态                   |
|    2 | `flight_progress`              | 飞行进度，按当前时间除以该次飞行最大时间并截断到$[0,1]$                                   | 0～1，无量纲                  | 用归一化位置表达飞行阶段，使不同时长的飞行可以按相对进度比较                 |
|    3 | `wind_speed`                   | 风传感器测得的风速标量                                                                    | m/s                           | 描述气流强度；较强风场可能改变抗风控制量和推进功率                           |
|    4 | `wind_sin`                     | 风向角转为弧度后的正弦值，即$\sin(\theta_i)$，其中 $\theta_i$ 是第 $i$ 个采样点的风向弧度 | -1～1，无量纲                 | 与`wind_cos` 共同连续表示风向，避免 0° 和 360° 的数值跳变                  |
|    5 | `wind_cos`                     | 风向角转为弧度后的余弦值，即$\cos(\theta_i)$，其中 $\theta_i$ 是第 $i$ 个采样点的风向弧度 | -1～1，无量纲                 | 与`wind_sin` 共同确定水平风向                                                |
|    6 | `programmed_speed_mps`         | 飞行任务给定的目标或程序速度，来自原始字段`speed`                                         | m/s                           | 表示任务规划要求，与实际速度之差可间接反映控制跟踪状态                       |
|    7 | `actual_speed_mps`             | 三轴速度的欧氏模长，$\sqrt{v_{x,i}^2+v_{y,i}^2+v_{z,i}^2}$                                | m/s                           | 描述无人机相对于地面的实际运动强度                                           |
|    8 | `horizontal_speed_mps`         | x、y 两轴速度的模长，$\sqrt{v_{x,i}^2+v_{y,i}^2}$                                         | m/s                           | 单独表示水平运动，避免竖直速度混入水平巡航状态                               |
|    9 | `vertical_speed_mps`           | 原始`velocity_z` 的有符号值                                                               | m/s                           | 描述上升或下降方向及速度；符号方向遵循源数据坐标定义                         |
|   10 | `vertical_speed_abs_mps`       | `vertical_speed_mps` 的绝对值                                                             | m/s                           | 只表示竖直运动强度，不区分上升与下降方向                                     |
|   11 | `relative_air_speed_mps`       | 无人机速度向量减去水平风矢量后的三维模长                                                  | m/s                           | 近似表示机体相对周围空气的速度，与气动阻力和推进负载相关                     |
|   12 | `wind_alignment`               | 水平速度与水平风矢量夹角的余弦近似，并截断到$[-1,1]$                                      | -1～1，无量纲                 | 接近 1 表示飞行与风大致同向，接近 -1 表示逆风，接近 0 表示近似侧风或速度很小 |
|   13 | `wind_cross_component_mps`     | 水平速度与水平风矢量二维叉积绝对值除以水平速度                                            | m/s                           | 表示垂直于飞行方向的侧风强度代理量                                           |
|   14 | `payload_kg`                   | 原始载荷`payload` 从 g 换算到 kg 后的质量                                                 | kg                            | 描述无人机额外承载质量；载荷变化会改变推力需求                               |
|   15 | `altitude_m`                   | 原始高度`altitude` 的米制表示                                                             | m                             | 描述任务高度，并供视觉与通信代理特征使用                                     |
|   16 | `dynamic_accel_norm`           | 三轴线加速度在 z 轴补偿重力后的模长                                                       | m/s²                         | 描述平动状态变化强度；快速加减速通常需要更大的瞬时控制输出                   |
|   17 | `angular_rate_norm`            | 三轴角速度的欧氏模长                                                                      | rad/s                         | 描述姿态转动强度，不区分具体绕哪个轴旋转                                     |
|   18 | `obstacle_agility_index`       | `dynamic_accel_norm`、`angular_rate_norm` 和绝对竖直速度的经验组合                        | 经验代理量，无严格物理单位    | 强调同时存在平动、转动和竖直机动的复杂工况；不是障碍物传感器直接测量值       |
|   19 | `thermal_load_proxy`           | 相对空气速度三次项、载荷动态项和向下/向上竖直运动项组成的经验特征                         | 经验代理量，不等同于 W 或温度 | 为网络提供非线性气动与载荷强度信息；各项未经过统一物理量纲标定               |
|   20 | `vision_energy_proxy_w`        | 由实际速度、敏捷度和高度线性组合得到的视觉计算能耗代理值                                  | 字段按 W 命名，但属于经验估计 | 表示代码假设的视觉处理负载变化，不是视觉计算机的实测分路功率                 |
|   21 | `communication_energy_proxy_w` | 由高度、风速和实际速度线性组合得到的通信能耗代理值                                        | 字段按 W 命名，但属于经验估计 | 表示代码假设的通信负载变化，不是通信模块的实测分路功率                       |
|   22 | `route_H`                      | 当`route` 为 H 时取 1，否则取 0                                                           | 0 或 1                        | 标记悬停类航线                                                               |
|   23 | `route_R1`                     | 当`route` 为 R1 时取 1，否则取 0                                                          | 0 或 1                        | 标记 R1 航线类别                                                             |
|   24 | `route_R2`                     | 当`route` 为 R2 时取 1，否则取 0                                                          | 0 或 1                        | 标记 R2 航线类别                                                             |
|   25 | `route_R3`                     | 当`route` 为 R3 时取 1，否则取 0                                                          | 0 或 1                        | 标记 R3 航线类别                                                             |
|   26 | `route_R4`                     | 当`route` 为 R4 时取 1，否则取 0                                                          | 0 或 1                        | 标记 R4 航线类别                                                             |
|   27 | `route_R5`                     | 当`route` 为 R5 时取 1，否则取 0                                                          | 0 或 1                        | 标记 R5 航线类别                                                             |
|   28 | `route_R6`                     | 当`route` 为 R6 时取 1，否则取 0                                                          | 0 或 1                        | 标记 R6 航线类别                                                             |

对每条样本，7 个航线变量中正常情况下只有一个等于 1，其余为 0。R1～R6 只是源数据集的航线类别编号，当前代码没有保存各路线的航点坐标，因此不能仅根据编号推断路线长度、转弯次数或几何形状。

### 3.3 预测输入

predict 模式接受两类 CSV：

1. 已处理特征表：包含 `feature_metadata.json` 中 `feature_columns` 给出的全部 28 个模型字段。`feature_columns` 是有顺序的字段名列表，程序按该顺序组成输入矩阵，不能随意交换列位置。
2. 原始数据表：包含 3.1 节列出的 19 个原始字段，程序重新执行数值转换、缺失值处理、特征工程和航线独热编码。

custom 模式可以生成默认工况，也可以读取自定义 CSV。自定义表缺失的模型特征会补 0。补 0 只保证张量维度完整，不代表该工况在物理上合理；正式预测应尽量提供完整特征。

### 3.5 输出数据中的字段

`uav_energy_features.csv`、`train.csv`、`val.csv` 和 `test.csv` 使用相同字段结构。前述 28 个模型输入不再重复列出，附加字段含义如下：


| 字段                 | 具体含义                                                                                           | 单位或取值 |
| -------------------- | -------------------------------------------------------------------------------------------------- | ---------- |
| `flight`             | 飞行任务编号，用于保证分组划分和飞行级汇总                                                         | 正整数     |

## 4. 标签与能量计算

### 4.1 瞬时功率标签

代码先把电池电流的负值截为 0，再计算功率：

$$
I_i^{+}=\max(I_i,0), \qquad
P_i=\max(U_i I_i^{+},0)
$$

其中：

- $i$：采样点索引。
- $I_i$：第 $i$ 个采样点的原始电池电流，单位 A。
- $I_i^{+}$：截断后的放电电流，单位 A。
- $U_i$：第 $i$ 个采样点的电池电压，单位 V。
- $P_i$：第 $i$ 个采样点的真实功率标签，单位 W。

### 4.2 采样间隔

同一次飞行内，相邻时间戳之差构成采样间隔。小于等于 0 s 或大于等于 5 s 的间隔被视为无效，并替换为全部有效间隔的中位数；若不存在有效间隔，则使用 0.2 s。

$$
\Delta t_i =
\begin{cases}
t_i-t_{i-1}, & 0<t_i-t_{i-1}<5,\\
\operatorname{median}(\Delta t_{\mathrm{valid}}), & \text{其他情况}.
\end{cases}
$$

其中：

- $t_i$：第 $i$ 个采样点的飞行时间，单位 s。
- $t_{i-1}$：同一次飞行内第 $i-1$ 个采样点的飞行时间，单位 s。
- $\Delta t_i$：第 $i$ 个采样区间的时长，单位 s。
- $\Delta t_{\mathrm{valid}}$：所有满足范围条件的时间间隔集合。
- $\operatorname{median}(\Delta t_{\mathrm{valid}})$：有效时间间隔集合的中位数，用作首个采样点和异常间隔的替代值。
- 5：代码允许的采样间隔上界，单位 s；等于或超过该值的间隔不直接用于能量积分。

### 4.3 区间电能与飞行总能耗

预测功率按矩形积分换算为 Wh：

$$
\hat E_i=\frac{\hat P_i\Delta t_i}{3600}, \qquad
\hat E_f=\sum_{i\in\mathcal I_f}\hat E_i
$$

其中：

- $\hat P_i$：第 $i$ 个采样点的预测功率，单位 W。
- $\hat E_i$：第 $i$ 个采样区间的预测电能，单位 Wh。
- $\Delta t_i$：第 $i$ 个采样区间的时长，单位 s。
- $f$：飞行编号。
- $\mathcal I_f$：属于飞行 $f$ 的采样点集合。
- $\hat E_f$：飞行 $f$ 的预测总能耗，单位 Wh。
- 3600：将 W·s 换算为 Wh 的单位转换系数。

## 5. 特征工程算法

### 5.1 风向和速度

风向角先转换为弧度，再分解成平面分量。飞行速度同时构造水平模长、三维模长和相对空气速度：

$$
\theta_i=\frac{\pi\alpha_i}{180}, \qquad
w_{x,i}=w_i\cos\theta_i, \qquad
w_{y,i}=w_i\sin\theta_i
$$

$$
v_{h,i}=\sqrt{v_{x,i}^{2}+v_{y,i}^{2}}, \qquad
v_i=\sqrt{v_{x,i}^{2}+v_{y,i}^{2}+v_{z,i}^{2}}
$$

$$
v_{\mathrm{air},i}=
\sqrt{(v_{x,i}-w_{x,i})^{2}+(v_{y,i}-w_{y,i})^{2}+v_{z,i}^{2}}
$$

其中：

- $\alpha_i$：风向角，单位 deg。
- $\theta_i$：风向弧度。
- $\pi$：圆周率；系数 $\pi/180$ 用于把角度制转换为弧度制。
- $w_i$：风速，单位 m/s。
- $w_{x,i}$、$w_{y,i}$：风在水平坐标系中的分量，单位 m/s。
- $v_{x,i}$、$v_{y,i}$、$v_{z,i}$：无人机三轴速度分量，单位 m/s。
- $v_{h,i}$：水平速度，单位 m/s。
- $v_i$：三维实际速度，单位 m/s。
- $v_{\mathrm{air},i}$：相对空气速度，单位 m/s。
- $\sin(\cdot)$、$\cos(\cdot)$：正弦和余弦函数，用于把一个风向角映射为连续的二维方向表示。
- $i$：当前采样点索引，同一组公式中的各变量均对应同一个采样时刻。

使用 wind_sin 和 wind_cos 表示角度，可以避免 0° 与 360° 在数值上相距很远。相对空气速度把无人机相对于地面的速度和风矢量合并，比单独使用地速更接近气动负载。

### 5.2 风向对齐与侧风

$$
a_{\mathrm{wind},i}=
\operatorname{clip}\left(
\frac{v_{x,i}w_{x,i}+v_{y,i}w_{y,i}}
{\max(v_{h,i}w_i,10^{-6})},
-1,1
\right)
$$

$$
c_{\mathrm{wind},i}=
\frac{|v_{x,i}w_{y,i}-v_{y,i}w_{x,i}|}
{\max(v_{h,i},10^{-6})}
$$

其中：

- $a_{\mathrm{wind},i}$：飞行方向与风向的对齐程度，无量纲；接近 1 表示同向，接近 -1 表示反向。
- $c_{\mathrm{wind},i}$：侧风分量代理，单位 m/s。
- $v_{h,i}$：水平速度，单位 m/s。
- $w_i$：风速，单位 m/s。
- $v_{x,i}$、$v_{y,i}$、$w_{x,i}$、$w_{y,i}$：水平速度和水平风分量，单位 m/s。
- $10^{-6}$：防止分母为 0 的数值稳定项。
- $\operatorname{clip}(x,-1,1)$：将输入 $x$ 限制在 -1 到 1 之间；小于 -1 的值置为 -1，大于 1 的值置为 1。
- $\max(a,b)$：返回 $a$ 与 $b$ 中较大的值，此处保证除数不会接近 0。

### 5.3 加速度、角速度与敏捷度

原始数据采用 NED 坐标系，静止时竖直加速度接近 $-g$，所以代码对 z 轴补偿重力：

$$
a_{d,i}=
\sqrt{a_{x,i}^{2}+a_{y,i}^{2}+(a_{z,i}+g)^{2}}, \qquad
\omega_i=
\sqrt{\omega_{x,i}^{2}+\omega_{y,i}^{2}+\omega_{z,i}^{2}}
$$

$$
q_{\mathrm{agility},i}
=a_{d,i}(1+\omega_i)+0.2|v_{z,i}|
$$

其中：

- $a_{x,i}$、$a_{y,i}$、$a_{z,i}$：三轴线加速度，单位 m/s²。
- $g$：重力加速度，代码取 9.80665 m/s²。
- $a_{d,i}$：重力补偿后的动态加速度模长，单位 m/s²。
- $\omega_{x,i}$、$\omega_{y,i}$、$\omega_{z,i}$：三轴角速度，单位 rad/s。
- $\omega_i$：角速度模长，单位 rad/s。
- $v_{z,i}$：竖直速度，单位 m/s。
- $q_{\mathrm{agility},i}$：避障或机动敏捷度代理量，由不同量纲的经验项组合而成，没有严格物理单位。
- 0.2：竖直速度项的经验系数。

敏捷度不是传感器直接测得的能耗，而是把平动加速度、转动强度和垂直运动组合成一个非线性特征。

### 5.4 热负载与子系统代理

$$
q_{\mathrm{thermal},i}
=0.5\max(v_{\mathrm{air},i},0)^3
+m_i a_{d,i}\max(v_i,0)
+\max(v_{z,i},0)(3.6+m_i)g
$$

$$
P_{\mathrm{vision},i}
=2.5+0.15v_i+0.30q_{\mathrm{agility},i}+0.002h_i
$$

$$
P_{\mathrm{communication},i}
=0.8+0.004h_i+0.04w_i+0.01v_i
$$

其中：

- $q_{\mathrm{thermal},i}$：热负载代理量，用于表达高速气流、载荷运动和竖直运动的综合强度；没有经过量纲统一，不是温度或真实热功率。
- $v_{\mathrm{air},i}$：相对空气速度，单位 m/s。
- $m_i$：载荷质量，单位 kg。
- $a_{d,i}$：动态加速度模长，单位 m/s²。
- $v_i$：实际速度，单位 m/s。
- $v_{z,i}$：竖直速度，单位 m/s。
- $g$：重力加速度，单位 m/s²。
- 3.6：代码假定的无人机基础质量项，数值按 kg 参与竖直运动项计算。
- $P_{\mathrm{vision},i}$：视觉计算能耗代理量，字段名单位写作 W。
- $P_{\mathrm{communication},i}$：通信能耗代理量，字段名单位写作 W。
- $q_{\mathrm{agility},i}$：敏捷度代理量。
- $h_i$：预设高度，单位 m。
- $w_i$：风速，单位 m/s。
- 0.5、2.5、0.15、0.30、0.002、0.8、0.004、0.04、0.01：代码设定的经验系数，其数值同时承担各输入项的尺度调整作用，并非通过本数据集单独标定出的物理常数。

这些代理量用于增强模型对工况的表达，不是经过硬件功率计分项标定得到的真实“热、视觉、通信功耗”。不能把它们的数值直接解释为各子系统的实际耗电。

### 5.5 飞行进度和航线

$$
r_i=\operatorname{clip}\left(\frac{t_i}{t_{f,\max}},0,1\right)
$$

其中：

- $r_i$：飞行进度。
- $t_i$：当前采样时间，单位 s。
- $t_{f,\max}$：当前飞行的最大时间，单位 s。
- $f$：当前飞行编号。
- $\operatorname{clip}(x,0,1)$：把比值限制到 0～1，使飞行进度不会超出定义范围。

航线 H、R1～R6 使用独热编码。`route_H`、`route_R1`、`route_R2`、`route_R3`、`route_R4`、`route_R5` 和 `route_R6` 分别表示当前样本是否属于对应航线，属于时取 1，否则取 0。当前数据中没有保留下来的 R7 样本，因此模型输入不存在 `route_R7` 列。

## 6. 标准化

所有均值和标准差只根据训练集计算，验证集、测试集和自定义工况复用相同参数：

$$
\tilde x_{ij}=\frac{x_{ij}-\mu_j}{\sigma_j}, \qquad
\tilde y_i=\frac{y_i-\mu_y}{\sigma_y}
$$

其中：

- $x_{ij}$：第 $i$ 个样本的第 $j$ 个原始特征。
- $\tilde x_{ij}$：标准化后的特征。
- $\mu_j$：训练集中第 $j$ 个特征的均值。
- $\sigma_j$：训练集中第 $j$ 个特征的标准差；小于 $10^{-6}$ 时替换为 1。
- $y_i$：第 $i$ 个样本的功率标签，单位 W。
- $\tilde y_i$：标准化后的功率标签。
- $\mu_y$：训练集功率标签的均值，单位 W。
- $\sigma_y$：训练集功率标签的标准差，单位 W。
- $i$：样本索引，范围从 1 到当前数据集的样本总数。
- $j$：特征索引，范围从 1 到 28。
- 波浪号 $\tilde{\ }$：表示变量已经按训练集统计量完成标准化，此时变量为无量纲数值。

当前 target_transform 配置为 none，没有对功率做对数变换。网络输出先反标准化为 W，再执行非负截断。

## 7. 模型详细架构

### 7.1 候选模型

代码比较普通 MLP 和残差 MLP：

- 普通 MLP：每层依次执行 Linear、BatchNorm1d、SiLU、Dropout，末层用 Linear 输出 1 个值。
- 残差 MLP：每个残差块包含两层 Linear、两层 LayerNorm、SiLU、Dropout和一条投影捷径，块输出再经过 SiLU。

各层名称的具体含义如下：


| 名称          | 具体含义                                                                           |
| ------------- | ---------------------------------------------------------------------------------- |
| `Linear`      | 全连接线性层，对输入执行权重矩阵乘法并加偏置；层后的两个数字表示输入维度和输出维度 |
| `BatchNorm1d` | 按训练批统计均值和方差的批归一化层，仅用于普通 MLP 候选                            |
| `LayerNorm`   | 对单个样本的特征维度做层归一化，不依赖同一批中的其他样本                           |
| `SiLU`        | 平滑激活函数$z/(1+e^{-z})$，为网络提供非线性表达能力                               |
| `Dropout`     | 训练时按给定概率随机把部分中间输出置为 0，评估和预测时关闭，用于降低过拟合         |
| `shortcut`    | 残差块的捷径分支；输入输出维度不同的时候使用可学习线性层完成维度投影               |

### 7.2 最终入选模型

本次训练选中 residual_256_128_64，结构为 **28 → 256 → 128 → 64 → 1**，可训练参数总数为 185473，Dropout 概率为 0.08。


| 层次     | 主分支                                                                | 捷径分支        | 输出维度 | 参数量 |
| -------- | --------------------------------------------------------------------- | --------------- | -------: | -----: |
| 输入     | 28 个标准化特征                                                       | 无              |       28 |      0 |
| 残差块 1 | Linear 28→256、LayerNorm、SiLU、Dropout、Linear 256→256、LayerNorm  | Linear 28→256  |      256 |  81664 |
| 残差块 2 | Linear 256→128、LayerNorm、SiLU、Dropout、Linear 128→128、LayerNorm | Linear 256→128 |      128 |  82816 |
| 残差块 3 | Linear 128→64、LayerNorm、SiLU、Dropout、Linear 64→64、LayerNorm    | Linear 128→64  |       64 |  20928 |
| 输出     | Dropout、Linear 64→1                                                 | 无              |        1 |     65 |

所有残差块都会改变维度，因此本次模型的三条捷径均为可学习线性投影，不是恒等映射。

### 7.3 残差块计算

设第 $l$ 个残差块输入为 $\mathbf h_l$，则：

$$
\mathbf z_l=
\operatorname{LN}\left(\mathbf W_{l,1}\mathbf h_l+\mathbf b_{l,1}\right)
$$

$$
\mathbf m_l=
\operatorname{LN}\left(
\mathbf W_{l,2}
\operatorname{Dropout}\left(\operatorname{SiLU}(\mathbf z_l)\right)
+\mathbf b_{l,2}
\right)
$$

$$
\mathbf h_{l+1}=
\operatorname{SiLU}\left(
\mathbf m_l+\mathbf W_{l,s}\mathbf h_l+\mathbf b_{l,s}
\right)
$$

其中：

- $l$：残差块编号。
- $\mathbf h_l$：第 $l$ 个残差块的输入向量。
- $\mathbf h_{l+1}$：第 $l$ 个残差块经过主分支、捷径分支相加和 SiLU 激活后的输出，同时作为下一残差块输入。
- $\mathbf z_l$：第一层线性变换和层归一化后的中间向量。
- $\mathbf m_l$：主分支的输出向量。
- $\mathbf W_{l,1}$、$\mathbf W_{l,2}$：主分支两层线性变换的权重矩阵。
- $\mathbf b_{l,1}$、$\mathbf b_{l,2}$：主分支的偏置向量。
- $\mathbf W_{l,s}$、$\mathbf b_{l,s}$：捷径投影的权重矩阵和偏置向量。
- $\operatorname{LN}$：LayerNorm。
- $\operatorname{Dropout}$：训练时随机丢弃部分神经元输出的正则化算子。
- 下标 1、2：分别表示主分支中的第一层和第二层线性变换。
- 下标 $s$：shortcut 的缩写，表示捷径投影分支。
- 粗体符号 $\mathbf h$、$\mathbf z$、$\mathbf m$、$\mathbf b$：表示向量；粗体 $\mathbf W$ 表示矩阵。

在最终模型的 3 个残差块中，输入维度和输出维度依次为 $(28,256)$、$(256,128)$ 和 $(128,64)$。因此 $\mathbf W_{l,1}$ 与 $\mathbf W_{l,s}$ 把输入投影到当前块输出维度，$\mathbf W_{l,2}$ 在当前块输出维度内继续变换。

SiLU 激活函数为：

$$
\operatorname{SiLU}(z)=z\sigma(z)=\frac{z}{1+e^{-z}}
$$

其中：

- $z$：神经元的线性输入。
- $\sigma(z)=1/(1+e^{-z})$：Sigmoid 函数，把输入映射到 0～1。
- $\operatorname{SiLU}(z)$：平滑、非单调的激活输出。
- $e$：自然对数的底数，此处出现在指数函数 $e^{-z}$ 中。

### 7.4 输出层与功率还原

3 个残差块得到 64 维向量后，模型先经过一个 Dropout 层，再通过线性层输出 1 个标准化功率值。预测阶段把该值还原到瓦特，并把负功率截断为 0：

$$
\hat{\tilde y}_i=\mathbf w_o^{\mathsf T}\operatorname{Dropout}(\mathbf h_3)+b_o
$$

$$
\hat P_i=\max\left(\sigma_y\hat{\tilde y}_i+\mu_y,0\right)
$$

其中：

- $\mathbf h_3$：第三个残差块输出的 64 维特征向量。
- $\mathbf w_o$：输出线性层的权重向量，把 64 维表示映射为 1 个数值。
- $\mathbf w_o^{\mathsf T}$：权重向量的转置，用于与 $\mathbf h_3$ 做内积。
- $b_o$：输出线性层的偏置标量。
- $\hat{\tilde y}_i$：第 $i$ 个样本在标准化功率空间中的预测值。
- $\sigma_y$：训练集真实功率的标准差，单位 W。
- $\mu_y$：训练集真实功率的均值，单位 W。
- $\hat P_i$：反标准化并执行非负截断后的预测功率，单位 W。
- $\max(\cdot,0)$：保证输出不小于 0；这一步属于预测后处理，不是网络内部的激活函数。

训练时 Dropout 处于启用状态以进行正则化，验证和预测时模型切换到评估模式，Dropout 不再随机丢弃特征。

残差连接允许主分支学习相对于投影输入的修正量。与普通 MLP 相比，本次验证结果中三个残差候选的综合选择分数均低于两个普通候选。

### 8.2 Huber 损失

网络在标准化功率空间计算 Huber 损失：

$$
L_\delta(e)=
\begin{cases}
\frac{1}{2}e^2, & |e|\le\delta,\\
\delta\left(|e|-\frac{1}{2}\delta\right), & |e|>\delta.
\end{cases}
$$

其中：

- $e=\hat{\tilde y}-\tilde y$：标准化预测值与标准化真实值之差。
- $\hat{\tilde y}$：网络输出的标准化预测功率。
- $\tilde y$：标准化真实功率。
- $\delta$：Huber 分段阈值，本实验取 0.65。
- $L_\delta(e)$：单样本损失。
- $|e|$：误差的绝对值，用于判断当前误差落在平方区间还是线性区间。
- 系数 $1/2$：使两个分段在 $|e|=\delta$ 处函数值连续，并使小误差段导数形式简洁。

小误差使用平方惩罚，大误差改为线性增长，能减弱瞬时异常功率对参数更新的支配作用。0.65 是标准化尺度，不是 0.65 W。

### 8.3 候选模型选择

每个候选模型训练 14 轮后，在验证集计算逐点功率 WAPE 和按 flight 积分后的能耗 WAPE。综合分数为：

$$
S=\operatorname{WAPE}_{\mathrm{flight}}
+0.2\operatorname{WAPE}_{\mathrm{sample}}
$$

其中：

- $S$：候选模型综合选择分数，越小越好。
- $\operatorname{WAPE}_{\mathrm{flight}}$：验证集飞行级能耗 WAPE，单位 %。
- $\operatorname{WAPE}_{\mathrm{sample}}$：验证集逐采样点功率 WAPE，单位 %。
- 0.2：逐点功率 WAPE 的权重。


| 候选模型            | 类型 | 隐藏维度   | Dropout |  学习率 | 验证功率 WAPE/% | 验证能耗 WAPE/% |  选择分数 |
| ------------------- | ---- | ---------- | ------: | ------: | --------------: | --------------: | --------: |
| residual_256_128_64 | 残差 | 256/128/64 |    0.08 | 0.00024 |           8.910 |           2.038 | **3.820** |
| residual_192_96_48  | 残差 | 192/96/48  |    0.06 | 0.00024 |           9.017 |           2.189 |     3.993 |
| residual_128_64_32  | 残差 | 128/64/32  |    0.05 | 0.00030 |           9.047 |           2.210 |     4.020 |
| plain_192_96_48     | 普通 | 192/96/48  |    0.08 | 0.00030 |          10.400 |           2.438 |     4.518 |
| plain_256_128_64    | 普通 | 256/128/64 |    0.08 | 0.00030 |          10.171 |           2.624 |     4.658 |

表中各列含义为：`候选模型` 是结构组合名称；`类型` 区分残差 MLP 和普通 MLP；`隐藏维度` 是三层隐藏表示的宽度；`Dropout` 是训练时随机丢弃概率；`学习率` 是候选训练的初始 AdamW 步长；`验证功率 WAPE` 衡量逐点功率总绝对误差比例；`验证能耗 WAPE` 衡量飞行积分后总能耗的绝对误差比例；`选择分数` 是公式 $S$ 的计算结果。

### 8.4 最终训练步骤

1. 固定 Python、NumPy 和 PyTorch 随机种子。
2. 检查 CUDA，模型参数、训练批和验证批均放到 GPU。
3. 仅用训练集构造特征和目标标准化参数。
4. 每个训练批执行前向传播、Huber 损失、反向传播、梯度范数裁剪和 AdamW 更新。
5. 每轮结束后在验证集计算平均 Huber 损失。
6. ReduceLROnPlateau 根据验证损失降低学习率。
7. 验证损失刷新最低值时复制当前权重；连续 10 轮未刷新时停止。
8. 训练结束后恢复最低验证损失对应的权重，而不是保留最后一轮权重。
9. 保存 checkpoint、标准化参数、训练日志、调参结果和损失曲线。

最终训练运行 42 轮，最低验证损失出现在第 32 轮：


| 项目                |     数值 |
| ------------------- | -------: |
| 最佳 epoch          |       32 |
| 最佳验证 Huber 损失 | 0.025959 |
| 同轮训练 Huber 损失 | 0.022629 |
| 同轮学习率          |  0.00006 |
| 实际停止 epoch      |       42 |

`最佳 epoch` 表示验证损失达到全程最低值的轮次；`最佳验证 Huber 损失` 是该轮验证集的平均损失；`同轮训练 Huber 损失` 是相同轮次训练批损失的平均值；`同轮学习率` 是该轮 AdamW 使用的步长；`实际停止 epoch` 是早停条件满足后程序结束的轮次。模型最终恢复第 32 轮权重，因此停止轮次不等于最终采用的权重轮次。

## 9. 评价指标

设测试样本数为 $n$，真实值为 $y_i$，预测值为 $\hat y_i$，误差为 $e_i=\hat y_i-y_i$：

$$
\operatorname{MAE}=\frac{1}{n}\sum_{i=1}^{n}|e_i|
$$

$$
\operatorname{RMSE}=
\sqrt{\frac{1}{n}\sum_{i=1}^{n}e_i^2}
$$

$$
R^2=
1-\frac{\sum_{i=1}^{n}e_i^2}
{\sum_{i=1}^{n}(y_i-\bar y)^2}
$$

$$
\operatorname{MAPE}=
\frac{100\%}{|\mathcal V|}
\sum_{i\in\mathcal V}
\left|\frac{e_i}{y_i}\right|,
\qquad
\mathcal V=\{i:|y_i|>10^{-6}\}
$$

$$
\operatorname{WAPE}=
100\%
\frac{\sum_{i=1}^{n}|e_i|}
{\max\left(\sum_{i=1}^{n}|y_i|,10^{-6}\right)}
$$

其中：

- $n$：评价对象数量。逐点功率指标中 $n=39761$ 个采样点；飞行能耗指标中 $n=30$ 次飞行。
- $i$：样本索引。
- $y_i$：第 $i$ 个评价对象的真实值；逐点评价时为真实功率，单位 W，飞行级评价时为真实累计能耗，单位 Wh。
- $\hat y_i$：第 $i$ 个评价对象的预测值，单位随评价层级分别为 W 或 Wh。
- $e_i=\hat y_i-y_i$：第 $i$ 个对象的有符号预测误差；正值表示高估，负值表示低估。
- $\bar y$：当前评价集合中全部真实值的算术平均值，单位与 $y_i$ 相同。
- $\mathcal V$：绝对真实值大于 $10^{-6}$ 的样本集合。
- $|\mathcal V|$：有效百分比误差样本数。
- $10^{-6}$：避免真实值为 0 时发生除零的数值阈值，单位随 $y_i$ 而定。
- $100\%$：把误差比例换算为百分数的系数。
- $\max(a,b)$：取 $a$ 与 $b$ 中较大的值，WAPE 分母至少取 $10^{-6}$。
- MAE：平均绝对误差，保持原单位。
- RMSE：均方根误差，对大误差更敏感。
- $R^2$：决定系数；1 为完全拟合，0 相当于均值基线，负值表示在当前集合上差于均值基线。
- MAPE：逐样本绝对百分比误差均值。
- WAPE：绝对误差总量相对于真实值总量的比例。

功率包含大量 0 或接近 0 的样本，因此功率 MAPE 会被很小的分母放大。该项目判断整体功率误差时应优先读 MAE、RMSE、$R^2$ 和 WAPE；MAPE 只适合在真实值远离 0 的区间辅助观察。

## 10. 测试结果

### 10.1 汇总指标

测试集包含 39761 个采样点和 30 次完整飞行。


| 层级     |      MAE |     RMSE |  $R^2$ |     MAPE |   WAPE |
| -------- | -------: | -------: | -----: | -------: | -----: |
| 逐点功率 | 36.456 W | 67.313 W | 0.9196 | 588.553% | 9.247% |
| 飞行能耗 | 0.630 Wh | 1.102 Wh | 0.9597 |   3.018% | 2.892% |

表中的“逐点功率”以 39761 个测试采样点为统计对象，MAE 和 RMSE 的单位为 W；“飞行能耗”先把每次飞行的功率按时间积分，再以 30 次飞行为统计对象，MAE 和 RMSE 的单位为 Wh。$R^2$ 没有单位，MAPE 和 WAPE 均为百分比。各指标的数学定义见第 9 节。

逐点功率 WAPE 为 9.247%，而积分后的飞行能耗 WAPE 为 2.892%。飞行级误差更低有两个原因：稳定巡航段占据较多采样点；同一次飞行中的正残差和负残差在积分后会部分抵消。因此，较好的飞行总能耗指标不等于每个瞬时尖峰都被准确复现。

功率 MAPE 达到 588.553%，主要由停机、起飞前和降落后的近零功率样本造成，不能据此直接否定模型的巡航段表现。

| 真实功率区间 | 样本数 | 真实均值/W | 预测均值/W |   MAE/W |   WAPE/% | 主要现象                   |
| ------------ | -----: | ---------: | ---------: | ------: | -------: | -------------------------- |
| 0–50 W      |   9549 |      1.250 |     24.927 |  24.067 | 1925.018 | 近零功率被系统性高估       |
| 50–300 W    |    704 |    162.658 |    218.931 | 115.537 |   71.030 | 样本最少，过渡工况误差最大 |
| 300–450 W   |   4471 |    409.917 |    450.782 |  54.238 |   13.231 | 整体偏高估                 |
| 450–600 W   |  19985 |    520.024 |    518.501 |  30.793 |    5.921 | 样本最多，均值偏差较小     |

表中“真实功率区间”按 `power_w` 划分；“样本数”是落入该区间的测试记录数量；“真实均值”和“预测均值”分别是区间内 `power_w` 与 `predicted_power_w` 的平均值；MAE 是区间内逐点绝对误差的平均值；WAPE 是区间内绝对误差总和除以真实功率绝对值总和。

模型把低功率区间向上拉、把高功率区间向下压，预测分布向占比最大的 450–600 W 巡航区间收缩。50–300 W 只有 704 个样本，MAE 为 115.537 W，说明起飞、降落和状态切换等短时过渡过程是当前模型的主要薄弱区域。

各功率分段的 $R^2$ 均为负值。分段后真实值变化范围变窄，使用该区间自身均值作为基线已经较强；负 $R^2$ 表明模型没有充分描述区间内部的细微变化。它与全测试集 $R^2=0.9196$ 并不矛盾。

### 10.3 单次飞行异常

30 次测试飞行中，flight 224 的真实能耗为 17.657 Wh，预测为 22.711 Wh，误差为 +5.054 Wh，绝对百分比误差为 28.622%，明显高于其他测试飞行。其余较大的绝对误差包括：

### 12.2 飞行级真实能耗与预测能耗

![飞行级真实与预测能耗](./figures/results/flight_energy_actual_vs_predicted.png)

- 横轴：flight 编号，按照真实能耗从低到高排序，不是时间顺序。
- 纵轴：单次飞行总能耗，单位 Wh。
- 蓝线：真实能耗；橙线：预测能耗。
- 读取方法：两条线越接近，单次飞行能耗越准确；持续位于同一侧表示系统性偏差。
- 当前结果：大多数飞行的两条线接近，模型能跟随 14～38 Wh 的飞行能耗变化。flight 224 的橙线明显高于蓝线，是测试集中最突出的高估样本；flight 272 也有较明显高估。

**flight 224 底层数据分析：**

flight 224 属于 H 航线，共有 1178 个采样点，积分时长为 176.73 s。真实能耗为 17.657 Wh，预测能耗为 22.711 Wh，净高估 5.054 Wh，对应绝对百分比误差 28.622%。误差并非均匀分布在整次飞行中，按真实功率区间拆分后得到以下结果：


| 数据范围              | 样本数 | 持续时间 | 真实平均功率 | 预测平均功率 | 对总能耗误差的贡献 |
| --------------------- | -----: | -------: | -----------: | -----------: | -----------------: |
| 真实功率不超过 50 W   |    289 |  43.51 s |      0.577 W |    455.908 W |          +5.504 Wh |
| 真实功率为 50～300 W  |     10 |   1.40 s |     69.740 W |    457.347 W |          +0.150 Wh |
| 真实功率为 300～450 W |     90 |  13.94 s |    436.700 W |    464.198 W |          +0.107 Wh |
| 真实功率为 450～600 W |    789 | 117.88 s |    486.407 W |    464.990 W |          -0.707 Wh |

真实功率不超过 50 W 的区间单独产生了 +5.504 Wh，已经超过最终的 +5.054 Wh 净误差。原因是 450～600 W 正常悬停区间存在 -0.707 Wh 的低估，抵消了部分低功率区间高估。因此，图中的异常不是模型在整次飞行中都把功率抬高，而是模型没有识别出末尾的功率状态切换。

逐点记录显示，从约 131.8 s 到 176.61 s 存在一段连续严重高估区间。该区间真实平均功率为 2.890 W，预测平均功率仍为 455.956 W，累计贡献 +5.654 Wh。若严格按真实功率不超过 50 W 判断，末尾连续低功率段从 133.8 s 开始，共 286 个采样点、43.01 s；飞行进度最后 15% 的真实平均功率只有 0.063 W。速度、角速度和动态加速度也同时降到很低。底层数据没有提供明确的“电机停转”或“着陆完成”标签，因此只能把该段判断为疑似着陆后或关机后的记录，不能仅凭功率值断言具体操作事件。

训练数据覆盖不足进一步解释了模型为何保持约 456 W 的悬停输出。训练集只有 flight 221 一次 H 航线飞行，共 809 行，占 174653 条训练记录的 0.463%；该飞行没有任何真实功率不超过 50 W 的样本，其最后 15% 进度内的真实平均功率仍为 469.132 W。模型在训练时看到的是“高飞行进度、低速度的 H 航线仍保持正常悬停功率”，没有见过 flight 224 这种持续 43 s 的末尾近零功率模式。

模型输入中不包含电机启停状态，电池电压和电池电流也只用于生成监督标签，不进入 28 维特征。对 H 航线而言，正常悬停本身就具有实际速度低、程序速度为 0、动态加速度较小的特点，因此这些变量下降不足以唯一表示关机。当前逐点 MLP 又不保存前后时刻状态，最终把疑似关机段继续判为正常悬停。flight 224 的主要问题可归结为 H 航线样本过少、训练集中缺少关机尾段，以及输入变量没有直接的飞行阶段或电机状态标志，而不是正常悬停功率关系整体失效。

针对这一误差，数据清洗阶段可以明确是否保留着陆后的记录；若需要预测完整任务过程，应增加 `motor_armed`、飞行阶段或着陆状态等不直接泄漏目标功率的输入，并在训练集中补充 H 航线的启动、稳定悬停和关机样本。直接把 `battery_current` 加入模型虽然能识别近零功率，但它同时参与真实功率标签计算，会形成明显的目标泄漏，不适合作为当前预测任务的常规改进。

## 15. 结果反映的主要问题

### 15.1 模型擅长稳定巡航和飞行总能耗

450–600 W 区间拥有约一半测试样本，真实均值与预测均值只相差约 1.52 W。模型能跟随不同飞行的总能耗变化，飞行级 $R^2$ 为 0.9597、WAPE 为 2.892%。在当前数据分布下，该模型更适合估算完整任务的能量需求，而不是复原每一个瞬时功率尖峰。

### 15.2 过渡工况和近零功率误差明显

50–300 W 区间样本少、MAE 高；0–50 W 区间的真实均值为 1.25 W，预测均值却为 24.93 W。起飞前、降落后、状态切换和异常突降是主要误差来源。若应用需要准确判断开机、停机或起飞瞬间，当前模型输出不能直接作为控制阈值。

### 15.3 预测存在向中间功率收缩

300–450 W 区间平均高估约 40.87 W，600 W 以上区间平均低估约 44.54 W。训练样本集中在 450–600 W 后，网络倾向输出更接近主流巡航功率的值。后续改进应优先考虑功率区间重采样、按阶段加权损失或单独建模起飞与降落阶段。

### 15.4 飞行级指标会掩盖局部错误

逐点功率 WAPE 为 9.247%，飞行能耗 WAPE 为 2.892%。积分降低误差并不意味着波形完全准确。flight 224 的能耗误差达到 +5.054 Wh，散点图中也存在数百 W 的离群误差。工程使用时应同时设置逐点、分阶段和飞行总量三类检查。

### 15.5 航线泛化证据不足

R1 占 182 次飞行，R2、R3、R4 各只有 1 次。当前按 flight 隔离避免了同一飞行泄漏，但没有解决航线分布不均衡。需要增加非 R1 航线数据，或采用按航线留一验证，才能判断模型对新路线的泛化能力。

### 15.6 代理特征不等同于可解释物理模型

thermal_load_proxy、vision_energy_proxy_w 和 communication_energy_proxy_w 使用代码设定的经验公式。它们有助于回归，但不能拆解真实机载子系统功耗。若目标是能耗机理识别，应增加电机、飞控、视觉计算机和通信模块的分路功率测量。

## 16. 推荐的阅读顺序

1. 查看 dataset_summary.json，确认本次数据规模和划分没有变化。
2. 查看 tuning_results_1.0.csv 与候选模型图，确认实际入选网络。
3. 查看 training_log_1.0.csv、损失曲线和学习率曲线，判断是否收敛。
4. 查看 evaluation_1.0.csv，读取全局功率与飞行能耗指标。
5. 查看 power_bin_evaluation_1.0.csv，定位具体功率区间的偏差。
6. 查看 flight_energy_summary_1.0.csv，排查单次飞行异常。
7. 结合散点图、残差图和三个 flight 时序图，判断误差属于整体偏差、离群点还是动态过程失真。
8. 自定义工况结果只用于给定输入下的模型推演，不应替代真实飞行验证。
