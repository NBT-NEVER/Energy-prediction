## 1. 实验方案

本项目用于四轴无人机瞬时功率和飞行能耗预测。项目按版本保存独立代码与实验产物，原始数据默认位于 `D:/Python-files/Energy-prediction/data`，各版本结果写入自己的 `out` 目录。测试集只在模型、时间窗和在线校正参数全部确定后使用。

项目统一采用以下评价对象：

- 采样点功率：MAE、RMSE、R2、MAPE、WAPE，单位为 W 或 %。
- flight 总能耗：先按采样间隔积分，再计算 MAE、RMSE、R2、MAPE、WAPE，单位为 Wh 或 %。
- 功率分箱、flight 汇总、预测区间和可视化结果作为补充分析。

## 2. 版本职责

| 版本 | 主要作用 | 模型与流程 |
|---|---|---|
| 1.0 | 建立功率和飞行能耗预测基线 | MLP/残差网络，逐点功率预测后按时间积分 |
| 2.0 | 引入时间卷积网络、RLS 在线校正、预测区间和自定义工况 | 因果 TCN 输出功率，RLS 逐采样点校正 |
| 2.1 | 规范模型选择流程 | 先选择 TCN 时间窗，再固定 TCN 预测搜索 RLS 参数 |
| 3.2 | 引入固定时间网格、时间感知 TCN 和每秒能量监督 | TCN 联合优化逐点功率与秒级能量，RLS 按状态和窗口在线更新，并增加能量窗变量分析 |

1.0、2.0、2.1 和 3.2 是并列实验版本。3.2 不覆盖 2.0 的代码或结果；2.0 目录同时保留 2.0 原始说明和 2.1 阶段新增说明。

## 3. 共同数据流

原始电压、电流、飞行状态和时间字段先经过数值转换、缺失值处理、航线筛选和特征工程，形成模型输入及真实功率标签：

$$P_i^{true}=\max(V_i I_i,0)$$

原始采样间隔不固定，程序按同一 flight 内相邻时间计算 $\Delta t_i$。采样区间能量为：

$$E_i=P_i^{true}\frac{\Delta t_i}{3600}$$

TCN 版本将历史输入组成因果时间窗，网络只接收当前及历史状态，输出当前采样点功率。3.2 先把 flight 重采样到统一 0.12 s 网格，将 `dt_seconds` 加入 TCN 输入，并把完整秒窗口能量误差回传到 TCN；RLS 在窗口结束后更新，能量窗作为独立变量分析。

## 4. 3.2 信息流

3.2 在工况、IMU、风场、代理量和航线独热特征中显式保留 `dt_seconds`，当前完整特征表包含 33 个模型输入字段；真实每秒能量不直接拼接到 TCN 前向输入。流程如下：

1. 时间感知 TCN 接收当前特征序列，输出逐采样点功率；训练时秒级能量差参与梯度更新。
2. 当前完整 1 秒窗口内，使用窗口开始前的仿射参数校正每个功率点。
3. 窗口结束后，分别积分 TCN 功率、RLS 校正功率和真实功率，得到三种每秒能量。
4. RLS 使用预测每秒能量和真实每秒能量计算窗口监督误差，更新偏置和比例参数。
5. 更新后的参数只传递到下一个窗口，不能回溯修改当前窗口。
6. 每个 flight 独立重置 RLS，停机/飞行状态切换时也恢复偏置 0、缩放 1。

3.2 搜索 0.25～16 s 的 10 个 TCN 时间窗候选，每组最多训练 80 轮，选定窗口后正式训练最多 80 轮；RLS 搜索 7 个遗忘因子与 7 个初始协方差组成的 49 组组合。RLS 能量窗不作为超参数，而在固定参数后独立比较 1、2、5、10、20 s 窗口对 MAE、RMSE、MAPE、R² 和 WAPE 等指标的影响。

## 5. 实验结果索引

3.2 的当前权重、最优 TCN 窗口、最优 RLS 参数和测试指标以最新完整运行生成的 `3.2/out/model/`、`3.2/out/rls/` 结构化文件为准。静态图统一输出 SVG，每条代表航线另提供可用鼠标旋转的 3D 轨迹 HTML 和高清 GIF。稳定运行说明见 `3.2/README.md`，当前算法与结果报告见 `3.2/out/outreadme.md`。

1.0、2.0、2.1、3.2 的完整结果展示、结果分析、变量解释、公式和图表路径均不在本页重复展开。3.2 将稳定项目说明、追加式改进日志和当次输出报告分别放在 `README.md`、`improve.md` 和 `out/outreadme.md`，避免历史结果与当前结果互相覆盖。

## 6. 运行方式

在对应版本目录执行：

```bash
python main.py all
```

3.2 完整重跑命令为 `python main.py all --device cuda --force-prepare`；补充结果常用命令为 `prepare`、`compare-rls-windows`、`route-visualize` 和 `test`。只有包含 TCN 搜索的 `tune-tcn`、`train` 和 `all` 模式清空终端日志，其余模式追加。数据缺失或不符合标准时，从 D 盘固定采样原表重建 `out/data`。
