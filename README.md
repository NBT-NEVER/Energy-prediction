# Energy-prediction

四轴无人机飞行能耗预测项目，按版本保存独立实验代码。各版本均以 `main.py` 为入口，原始数据默认来自 `D:/Python-files/Energy-prediction/data`，处理结果写入对应版本的 `out`。

## 版本概览

| 版本 | 作用 | 主要方法 |
|---|---|---|
| 1.0 | 建立无人机瞬时功率与飞行能耗预测基线 | TCN、逐点功率积分、flight级能耗评估 |
| 2.0 | 在 1.0 基础上加入 RLS 在线功率校正、区间预测和自定义工况 | TCN + 逐采样点 RLS |
| 2.1 | 修正模型选择流程，先选 TCN 时间窗，再固定 TCN 预测搜索 RLS 参数 | 两阶段 TCN + RLS |
| 3.0 | 将 RLS 监督粒度改为不规则采样下的完整 1 秒能量窗口，并输出秒级能量对比 | TCN 逐点功率 + 秒级能量监督 RLS |

## 版本关系

`1.0`、`2.0`、`2.1` 和 `3.0` 是相互独立的实验目录。`3.0` 保留 2.1 的输入特征、TCN 结构、候选时间窗、RLS 候选网格、数据切分和不确定性输出，同时新增秒级能量数据表、窗口级 RLS 更新和秒级能量图表。旧版本文件不被 3.0 覆盖。

## 3.0 算法

原始数据的采样间隔不固定，程序按同一 flight 内的时间差计算 `dt_seconds`。每个采样点的真实功率为电池电压乘以非负放电电流：

$$P_i^{true}=\max(V_i I_i,0)$$

其中：

`$P_i^{true}$`：第 `$i$` 个采样点的真实功率，单位 W。

`$V_i$`：电池电压，单位 V。

`$I_i$`：电池电流，单位 A。

`$dt_i$`：第 `$i$` 个采样间隔，单位 s。

每秒能量按时间积分，而不是按采样点数量平均：

$$E_{f,k}=\sum_{i\in W_{f,k}}\frac{P_{f,i}dt_{f,i}}{3600}$$

其中：

`$E_{f,k}$`：flight `$f$` 的第 `$k$` 个时间窗口能量，单位 Wh。

`$W_{f,k}$`：flight `$f$` 的第 `$k$` 个 1 秒窗口中的采样点集合。

`$P_{f,i}$`：窗口内第 `$i$` 个采样点的功率，单位 W。

`$dt_{f,i}$`：对应采样间隔，单位 s。

TCN 仅接收 2.1 的 22 维工况特征，输出逐采样点功率。每个窗口结束后，系统将 TCN 功率积分为预测能量，并将预测能量与真实能量转换成窗口平均功率，作为 RLS 的输入和监督目标。RLS 更新后的仿射参数只作用于下一个窗口，因此当前窗口不会使用尚未结束的真实能量。

RLS 超参数仍使用 2.1 的 72 组候选：遗忘因子 0.95、0.97、0.98、0.99、0.995、0.999；初始协方差 100、500、1000、5000；预热 0.5、1.0、2.0 秒。每个 flight 单独重置参数。最终选择依据验证集所有 flight 的等权汇总价值函数，不使用测试集选参。

## 运行

在版本目录执行：

```bash
python main.py all
```

也可以执行 `python main.py prepare`、`python main.py train`、`python main.py evaluate` 和 `python main.py visualize`。3.0 运行结果位于 `3.0/out`，详细算法、数据流、变量和本次结果见 `3.0/out/out_README.md`。
