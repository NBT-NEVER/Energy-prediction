# Energy-prediction 项目说明

## 1. 实验方案

本项目用于四轴无人机瞬时功率和飞行能耗预测。项目按版本保存独立代码与实验产物，原始数据默认位于 `D:/Python-files/Energy-prediction/data`，各版本结果写入自己的 `out` 目录。测试集只在模型、时间窗和在线校正参数全部确定后使用。

项目统一采用以下评价对象：

- 采样点功率：MAE、RMSE、R2、MAPE、WAPE，单位为 W 或 %。
- flight 总能耗：先按采样间隔积分，再计算 MAE、RMSE、R2、MAPE、WAPE，单位为 Wh 或 %。
- 功率分箱、flight 汇总、预测区间和可视化结果作为补充分析。

## 2. 版本职责

| 版本 | 主要作用 | 模型与流程 |
|---|---|---|
| 1.0 | 建立功率和飞行能耗预测基线 | MLP/残差网络，逐点功率预测后按时间积分 |
| 2.0 | 引入时间卷积网络、RLS 在线校正、预测区间和自定义工况 | 因果 TCN 输出功率，RLS 逐采样点校正 |
| 2.1 | 规范模型选择流程 | 先选择 TCN 时间窗，再固定 TCN 预测搜索 RLS 参数 |
| 3.0 | 引入不规则采样下的每秒能量监督 | TCN 逐点功率预测，完整 1 秒窗口积分，RLS 按窗口更新 |

1.0、2.0、2.1 和 3.0 是并列实验版本。3.0 不覆盖 2.0 的代码或结果；2.0 目录同时保留 2.0 原始说明和 2.1 阶段新增说明。

## 3. 共同数据流

原始电压、电流、飞行状态和时间字段先经过数值转换、缺失值处理、航线筛选和特征工程，形成模型输入及真实功率标签：

$$P_i^{true}=\max(V_i I_i,0)$$

原始采样间隔不固定，程序按同一 flight 内相邻时间计算 $\Delta t_i$。采样区间能量为：

$$E_i=P_i^{true}\frac{\Delta t_i}{3600}$$

TCN 版本将历史输入组成因果时间窗，网络只接收当前及历史状态，输出当前采样点功率。RLS 版本再依据已到达的真实反馈校正输出。3.0 将采样点能量按 `flight + floor(time)` 聚合为每秒能量，并在窗口结束后更新 RLS。

## 4. 3.0 信息流

3.0 继续使用 2.1 的 22 维输入，真实每秒能量不直接拼接到 TCN 输入。流程按以下顺序执行：

1. TCN 接收 22 维工况特征序列，输出逐采样点功率。
2. 当前完整 1 秒窗口内，使用窗口开始前的仿射参数校正每个功率点。
3. 窗口结束后，分别积分 TCN 功率、RLS 校正功率和真实功率，得到三种每秒能量。
4. RLS 使用预测每秒能量和真实每秒能量计算窗口监督误差，更新偏置和比例参数。
5. 更新后的参数只传递到下一个窗口，不能回溯修改当前窗口。
6. 每个 flight 独立重置 RLS，最终输出逐点功率、每秒能量、累计能量及对比图。

3.0 本次使用 10 个 TCN 时间窗候选：0.25、0.5、1、2、4、6、8、10、12、16 秒，4 秒位于候选中间；TCN 候选和最终训练均为 80 epoch。RLS 使用 72 组候选：遗忘因子 0.85、0.90、0.93、0.95、0.97、0.99；初始协方差 10、25、50、100；预热 0.1、0.25、0.5 秒。

## 5. 实验结果索引

3.0 最近一次重训选择 TCN `2.0 s / 17 步`，RLS 选择遗忘因子 0.97、初始协方差 10、预热 0.1 秒。测试集 RLS 校正后样本功率 WAPE 为 7.7784%，flight 能耗 WAPE 为 1.1391%。完整 TCN 候选、RLS 候选、功率分箱、flight 汇总、每秒能量和预测区间结果，分别见 3.0 的完整 out_readme 与输出 CSV/JSON。

1.0、2.0、2.1、3.0 的完整结果展示、结果分析、变量解释、公式和图表路径均不在本页重复展开，统一归档于 `README/`；版本目录内的 `README.md` 与对应 `out/out_README.md` 保持一致。

## 6. 运行方式

在对应版本目录执行：

```bash
python main.py all
```

常用分步命令为 `prepare`、`train`、`evaluate`、`visualize`。3.0 运行时会检查处理后数据；数据缺失或不符合标准时，从 D 盘原始数据重新计算并写入 `out/data`。
