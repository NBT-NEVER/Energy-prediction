# 4.0 改进日志

## 记录规范

本文件采用追加式记录，保留 3.2 迁移带来的历史背景，并记录 4.0 的实现、验证和产物变化。指标只引用本目录实际生成的 CSV/JSON；没有测量依据的效果标为“未验证”。

## 2026-09-16：4.0 任务规划版本建立

- **修改范围**：`config.py`、`data_utils.py`、`model.py`、`train.py`、`evaluate.py`、`task_api.py`、`main.py` 及三份说明文档。
- **处理方式**：从 3.2 独立复制出 4.0，建立独立 `model/`、`out/`、日志和配置；3.2 未被回写。
- **输入契约**：TCN 只读取任务前规划速度、加速度、高度、风预报、载荷和轨迹派生量；route 保留查询用途但不进入特征；电压、电流和真实功率只用于离线标签或窗口结束后的实际能耗。
- **数据处理**：排除 A1/A2/A3；按完整 flight 划分；原始中位采样周期约 0.12 s，重采样周期统一为 0.2 s，并生成 `resample_map_4.0.csv`。
- **超参数规模**：TCN 时间窗 1/2/3/4/5 s 共 5 组；RLS 遗忘因子和初始协方差各 5 个候选，共 25 组；不进行消融实验。
- **在线逻辑**：RLS 只接收完整窗口的基线预测能耗和窗口结束后的实际能耗；更新后重新修正剩余整条路线，已执行窗口保持实际观测值。

## 2026-09-16：首次完整运行（GPU）

- **运行设备**：NVIDIA GeForce RTX 3060 Laptop GPU，PyTorch `2.11.0+cu128`，`cuda_available=True`。
- **数据产物**：正常飞行 200 个 flight、188,879 个 0.2 s 样本；train/val/test 为 132,620/27,393/28,866 行，A1/A2/A3 不在处理结果中。
- **TCN 搜索**：5 个候选均完成，当前验证集最优为 2.0 s（10 步）；正式训练 8 轮完成，权重写入 `model/final_planning_tcn_4.0.pt`。
- **RLS 搜索**：25 组组合全部完成，当前选择遗忘因子 0.98、初始协方差 2.0。
- **测试结果**：样本功率 WAPE 16.51%；时间窗能耗 WAPE 15.23%；flight 总能耗 WAPE 4.12%；flight 能耗区间覆盖率 100%。这些结果仅用于 4.0 当前数据划分的离线评估，不代表所有新路线和新风场均已验证。
- **接口演示**：生成新路线 `NEW_ROUTE_X` 的任务前 40 s 规划和一次窗口结束后的在线 RLS 更新；任务前总能耗 2.99 Wh，95%区间为 2.65–3.33 Wh。
- **输出影响**：新增 `out/predictions/`、`out/tasks/`、`out/figures/`、`out/model/evaluation_4.0.json` 和 `out/rls/rls_tuning_4.0.csv`。调度器应读取 CSV/JSON，不能只读取图表。
