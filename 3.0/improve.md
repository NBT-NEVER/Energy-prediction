## RLS 在线机制

- 每个 flight 独立从偏置 0、缩放 1 开始。用 TCN 窗口平均功率 50 W 作为停机/飞行阈值，状态切换时恢复中性参数与初始协方差。
- 当前窗口先使用旧参数校正功率；窗口结束后才获得真实能量。RLS 回归量使用未经校正的 TCN 窗口能量，监督目标使用真实窗口能量，更新参数仅作用于下一窗口。
- 预热参数从不足 1 秒、实际难以区分的秒数改为 0、1、2、3 个完整窗口；不完整末窗口不参与更新。
- 价值函数增加 flight 能量误差 95 分位和 flight 间标准差惩罚，降低单个 flight 过度校正风险。
- 新网格共 196 组，最优为遗忘因子 0.91、初始协方差 0.25、预热 0 窗口，价值函数 6.12551123。遗忘因子与协方差均不在边界。

## 启动方式与产物

- `python main.py tune-tcn`：只搜索 TCN 并保存最优阶段模型。
- `python main.py train-fixed`：显示当前 TCN 参数，跳过搜索完成正式训练。
- `python main.py tune-rls`：加载现有 TCN，只搜索 RLS 并写回最优参数。
- `python main.py test`：只运行固定模型与 RLS 参数的测试、评估和制图。
- RLS 调参表、参数轨迹、统计、置信区间和参数变化图统一放入 `out/rls`。
- 功率与每秒能量时序图同时展示真实值、纯 TCN 和 RLS 校正值。

## 本次实验结果

- 固定 2.0 s/17 步 TCN 最多训练 80 轮，第 63 轮早停，最佳权重来自第 53 轮，验证联合损失 0.01641463。
- 测试集纯 TCN / RLS 功率 WAPE 为 7.7114% / 6.8371%，RLS 功率 RMSE 43.0377 W、R2 0.9630。
- 测试集纯 TCN / RLS 整 flight 能量 WAPE 为 2.7966% / 0.3079%，RLS 能量 RMSE 0.1135 Wh、R2 0.9994。
- 测试轨迹含 5442 个秒窗口、61 次状态切换。偏置归一化系数均值 0.00697，缩放系数均值 0.97398；少量窗口触及参数裁剪边界，后续可考虑增加连续越界计数或平滑更新约束。
