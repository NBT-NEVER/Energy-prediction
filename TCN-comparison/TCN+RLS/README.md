## 实验范围

本目录在 `../TCN` 已完成的 A/B/C/D 四组 TCN 功率基线上加入因果 RLS。RLS 只在一个完整反馈时间窗结束、取得该窗实际能耗后更新；当前时间窗使用更新前状态预测。RLS 搜索同时包含遗忘因子、初始协方差和时间窗长度。实验不重新训练 TCN，便于把新增差异限定为 RLS 和区间评估。

置信区间采用与在线更新相同的因果模拟顺序。验证 flight 按排序后的序列索引交替拆分：`[::2]` 的15个 flight 用于 RLS 超参搜索，`[1::2]` 的14个 flight 用于区间倍率校准；测试集只用于最终评价。名义置信水平为 95%，同时报告任务前、窗口级和反馈后在线覆盖率、平均区间宽度、区间评分以及按任务阶段抽取的覆盖率。

SMA 通道为三维规划位置和二维风分量，按 flight 分组、只使用当前与历史值计算。原始10维为任务时间、任务总时长、三维规划位置、二维风、载荷、电机状态和离地状态；完整字段及单位见 [TCN字段说明](../TCN/README.md#原始字段与派生字段)。TCN 的两个残差块通道均为32，卷积核3，膨胀率1和2，GroupNorm(1,32)，Dropout=0.05；预测头为 Linear(32,32)、SiLU、Linear(32,1)。混合激活仅在残差出口使用ReLU，统一SiLU组替换该出口，最终回归层仍为线性。

训练采用SmoothL1Loss、AdamW、学习率3e-4、权重衰减1e-4、批大小2048、梯度裁剪2.0。采样间隔0.2s，SMA固定10步（2s）；TCN窗口候选为0.6、1、2、3、4、5、8、10s，每候选完整20轮，正式完整80轮，无提前停止，种子42。权重保留验证损失最低轮次，标准化器仅由训练集拟合。本轮读取的权重元数据为：

RLS 搜索网格：遗忘因子 `[0.85, 0.88, 0.9, 0.93, 0.96, 0.98, 0.99]`，初始协方差 `[0.05, 0.1, 0.25, 0.5, 1.0, 2.0, 4.0]`，时间窗 `[1.0, 2.0, 5.0, 10.0, 20.0]` s，共 245 个候选/组。每个flight重置RLS，初始偏置0、比例1，协方差对角元为初始系数乘以1e-4和初始系数；残差标准差初值0.01Wh，方差更新权重0.15。比例裁剪到0.25～1.75，偏置幅值不超过当前实际窗口能耗。所有候选完整模拟，按验证搜索子集逐窗累计任务能耗WAPE最小选取。

## 文件结构

- `config.py`：数据、模型、输出路径和RLS搜索网格。
- `rls.py`：RLS更新、区间和覆盖率计算。
- `rls_evaluate.py`：TCN基线加载、RLS调参、区间校准与测试评价。
- `visualize_rls.py`：误差、覆盖率、宽度、窗口搜索和在线轨迹图。
- `main.py`：统一入口。
- `out/results/`：四组调参、校准、逐窗口、逐flight和汇总CSV/JSON。
- `out/figures/`：PNG和SVG图表，包括误差、覆盖率、时间窗搜索、在线区间和阶段覆盖率。
- `out/logs/`：终端及运行记录。

## 边界与解释

RLS 使用的是完整窗口实际能耗反馈，属于离线回放的在线校正模拟。TCN全部预推理仅使用加工规划特征，未来实际功率只在对应窗口结束后作为反馈；原始规划位置、风和运行状态仍来自实飞代理，不能据此判断独立计划轨迹和预报风场下的部署精度。区间是面向未来观测值的预测区间，不是模型均值参数的置信区间。校准采用同一套残差比率分位数规则，各组倍率不同；任务倍率混合任务起点和多个在线阶段，未单独保证起点或每个阶段95%覆盖。校准flight也曾用于已有TCN的验证选择，因此不是完全独立于整个建模过程的校准集。同一flight内部有时间相关性，无理论覆盖保证或多种子显著性结论。
